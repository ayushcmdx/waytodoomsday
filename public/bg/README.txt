Drop your background video clips in this folder, named like:
  doomsday-1.mp4
  doomsday-2.mp4
  doomsday-3.mp4
  ...

Then open src/components/BackgroundVideo.jsx and list them (in play order)
in the PLAYLIST array at the top of the file. Add as many as you like -
when the last one finishes it automatically loops back to the first.

Keep each clip reasonably sized (a few MB, like the ones you're using now)
so the page doesn't feel slow to load.
